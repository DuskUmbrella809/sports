# ⚽ SPORTS

A modern terminal-based sports dashboard built with Python and Textual.

![Python](https://img.shields.io/badge/Python-3.14-blue)
![Textual](https://img.shields.io/badge/Textual-TUI-green)
![License](https://img.shields.io/badge/License-MIT-orange)

---

## Features

- ⚽ Live football matches
- 🏆 League grouping
- 📊 Interactive match table
- 🔍 Search (In Progress)
- 📄 Match Details
- 🔄 Automatic refresh
- 🛡 API timeout protection
- 🖥 Linux support

## Installation

```bash
git clone https://github.com/DuskUmbrella809/sports.git

cd sports

python -m venv .venv

source .venv/bin/activate

pip install -e .

sports
```
